# Changelog

Each release gets a `## <version>` section; CI copies the one matching `shared/version.h` into the GitHub Release notes. Add entries under `Unreleased` as you go, then rename it to the version when you bump.

## 1.0.1 - 2026-10-03

- INSERT closes the menu even while a server dialog is open, and closing the menu no longer takes the dialog's cursor away.
- Rounded panels and text draw correctly even when the game or another mod leaves unusual graphics settings behind.

## 1.0.0 - 2026-10-03

- YapNotifierSA is now live! Based on the original YapNotifier for FiveM, it has now been adapted to work with GTA San Andreas!
